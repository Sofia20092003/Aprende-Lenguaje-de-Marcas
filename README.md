
# Práctica 1: Grid y Flexbox - Diseño de Interfaces Web

Este repositorio contiene el código de la **Práctica 1** de la asignatura **Diseño de Interfaces Web / Lenguaje de Marcas**. El objetivo del proyecto es maquetar una aplicación web adaptable (responsive) utilizando HTML5 semántico, CSS Flexbox y CSS Grid.

* **Sofía** 
* **Íker** 
* **Fran** 


## 🛠️ Tecnologías Utilizadas

* **HTML5**: Estructura semántica del contenido (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
* **CSS3**: Estilos externos, variables CSS, maquetación flexible con **Flexbox** y rejillas con **CSS Grid**
* **Diseño Responsive**: Adaptación a pantallas de escritorio, tabletas y móviles
* **Git / GitHub**: Control de versiones durante el desarrollo


## 🚀 Características Destacadas

* **HTML Semántico y Validado**: Estructura según los estándares de W3C
* **Uso de Flexbox**: Utilizado para la alineación del menú de navegación y del pie de página
* **Uso de CSS Grid**: Utilizado para la distribución de tarjetas y secciones 
* **Adaptabilidad**: Rediseño para pantallas pequeñas sin desbordamientos laterales
